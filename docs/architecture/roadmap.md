# Roadmap

## v1.0 — Minimum Viable Product

* Room creation
* Room joining
* WebSocket signaling
* SDP negotiation
* ICE candidate exchange
* WebRTC DataChannel
* Peer-to-peer chat
* Streaming large file transfer
* Progress reporting
* Web client
* Python CLI

## v1.1 — Usability

* Drag-and-drop uploads
* Improved transfer queue
* Better CLI experience
* UI improvements

## v2.0 — Reliable Transfers

* Resume interrupted transfers
* Chunk acknowledgements
* Retry failed chunks
* Integrity verification
* Adaptive chunk sizing
* Transfer history

## v3.0 — Multi-Peer Rooms

* Multiple participants
* Group chat
* Broadcast messaging
* Peer management
* Multi-peer file distribution

## v4.0 — Security

* Password-protected rooms
* Application-layer end-to-end encryption
* Device verification
* TURN relay fallback
* Secure key verification
